# chezmoi-dotfiles

macOS dotfiles managed with [chezmoi](https://www.chezmoi.io/).

## Setup

1. Install [Homebrew](https://brew.sh/)
2. Install [chezmoi](https://www.chezmoi.io/)

```sh
brew install chezmoi
```

3. Apply the dotfiles.

```sh
chezmoi init --apply https://github.com/naniroquai/chezmoi-dotfiles.git
```
